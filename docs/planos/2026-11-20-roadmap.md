# Roadmap de implementação

**Spec:** `docs/specs/2026-11-20-regulacao-sinistros-climaticos-design.md`
**Princípio:** cada fase tem o seu próprio plano detalhado, escrito quando a fase anterior termina, já com os resultados das verificações do ambiente. Cada fase termina com uma entrega testável e com commit.

| Fase | Entrega | Depende de | Plano |
|---|---|---|---|
| **0. Ambiente** | FEVM criado; profile `fe-bar`; projeto Python (uv + pytest); catálogo, schemas e volumes; verificações de recursos em `evidencias/00a-verificacoes-ambiente.md`; esqueleto do bundle | — | `2026-11-20-fase-0-1-ambiente-e-dados.md` |
| **1. Dados** | Dados públicos preparados (INMET 2025/2026, municípios, Defesa Civil); gerador sintético testado (cadastros, preços, histórico 2025, avisos 2026 com PDFs, gabarito); base no Volume; `simular_evento.py` | 0 | `2026-11-20-fase-0-1-ambiente-e-dados.md` |
| **2. Pipeline bronze e silver** | SDP com Auto Loader; `ai_parse_document` + `ai_query` para extrair os documentos; cruzamento com apólice e clima; evidência climática com duas fontes; expectations; teste com o lote 1 | 1 | `2026-11-20-fase-2-pipeline-bronze-silver.md` |
| **3. Modelo de suspeita** | Features compartilhadas; treino no histórico 2025; MLflow completo (métricas, artefatos, SHAP, `log_input`); registro no UC com alias `champion` | 2 (features) | `2026-11-20-fase-3-modelo-suspeita.md` ✅ |
| **4. Parecer e avaliação** | `gerar_parecer()` com validação de schema; Prompt Registry; modelo MLflow servido com tracing e AI Gateway; avaliação v1 × v2 com `mlflow.genai.evaluate` | 2 | a escrever |
| **5. Gold e orquestração** | Score + parecer + prioridade e fast track no gold; `job_evento` disparado por chegada de arquivo; tratamento de falhas (parecer pendente e nova tentativa) | 3, 4 | a escrever |
| **6. Lakebase e laço de retorno** | Projeto Lakebase; synced tables; schema `operacao` (atribuições, decisões, reanálises); Lakehouse Sync (ou o plano B); `job_retreino` com champion/challenger | 5 | a escrever |
| **7. Governança, metric views e Genie** | Grupos, grants, tags LGPD, máscaras e filtros (ABAC ou funções); `mv_sinistros` e `mv_exposicao`; Genie Agent com benchmarks | 5 | a escrever |
| **8. App** | AppKit com as 5 telas; Lakebase + SQL Warehouse + Genie + endpoint; deploy via DAB | 6, 7 | a escrever |
| **9. Evidências e documentação** | `coletar_evidencias.py` (01 a 09); notebooks exportados com saída; `arquitetura.md`, `uso-de-ia.md`, `roteiro-demo.md`; README final | 8 | a escrever |
| **10. Deck, ensaio e publicação** | Deck em PDF; ensaio do roleplay; varredura de segredos; repo público (com autorização do autor) | 9 | a escrever |
